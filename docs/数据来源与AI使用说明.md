# 数据来源与AI使用说明

数据来源：杭州文化和旅游数据在线开放平台。
网址：https://data.wgly.hangzhou.gov.cn/home/#/dataPlatform/ssDatabase
下载日期：2026-10-22。
方法：官方查询界面的“下载原始数据”，不是爬虫。
范围：全市及13区县“所有档次酒店”的日度入住率，分析期2023-11-01至2025-12-31。
原件：data/raw/city_daily.xlsx和district_daily.xlsx，SHA-256摘要见outputs/tables/source_manifest.json。
真实记录：全市791条，区县10294条。预测表另含1个标记补值，不计入真实记录数。

许可依据为平台服务条款，非排他免费使用，不得有偿售卖，须标注来源、日期与个人研究性质；下游继续受来源协议约束。条款原件随项目归档。

OpenAI Codex参与要求拆解、来源筛选与数据核验辅助、Python代码及论文初稿生成、图表和大屏设计、文字润色与排版检查。真实数据、计算输出与图形均经过实际运行，不使用AI虚构观测。AI使用范围包含正文草拟，不能只称拼写辅助。作者应在提交前理解代码并核查结论，遵守课程有关独立完成和AI使用的要求。
